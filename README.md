# ✨ Sparkle Login — Cute & Modern UI

Un login moderno con estética _girly/pastel_, cambio entre **Modo Claro** y **Modo Oscuro**, brillitos interactivos y animaciones activadas por scroll.

## Características

- **Modo Claro & Oscuro:** Alterna entre paleta _Cotton Candy_ y _Midnight Berry_ guardando la preferencia.
- **Brillitos dinámicos:** Partículas flotantes de fondo y destellos al mover o hacer clic con el cursor.
- **Scroll interactivo:** Barra de progreso superior, efecto parallax y tarjetas con animación _reveal_.
- **100% HTML, CSS y JavaScript puro:** Listo para desplegar gratis en GitHub Pages.
